# Автотест к API - создание заказа и проверка получения данных по номеру трека

Нужен *запущенный* сервер.

1. Запустить сервер на платформе Яндекс.Практикум.
2. Заменить URL в `configuration.py` на новый.
3. Установить библиотеки `requests` и `pytest`.
4. Запустить тесты кнопкой **Run** через IDE.
"При возникновении ошибок на стороне сервера, логи доступны по пути /var/www/backend/logs/error.log".
